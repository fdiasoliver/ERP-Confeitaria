# .claude/templates/

Pasta de modelos reutilizáveis de documentos do processo de sprint.

## Arquivos

| Arquivo | Propósito |
|---|---|
| `SKILL_TEMPLATE.md` | Modelo oficial obrigatório para criar qualquer nova Skill — gera `SKILL.md` (maiúsculo) já na estrutura de 11 seções oficiais. Ver `.claude/skills/project-skill-governance/SKILL.md` (checklist de criação) e `references/skill-format.md` (procedimento completo) para o fluxo de validação que toda Skill nova deve passar antes de ser incorporada ao projeto. |

**Ainda não populados** (candidatos identificados na Sprint G.5.0, não criados ainda): os 4 templates de `PROJECT_GOVERNANCE.md` Seções 19–22 (Sprint, Revisão Técnica, QA, Critérios de Aceite); os templates de `SPRINT_X.md`/`SPRINT_AUDIT.md` de `AI_PROMPT_ORCHESTRATOR.md` Seção 5; o template de prompt "ORCHESTRATOR — Criação de Skill Claude Code" (candidato de `.claude/prompts/`, não desta pasta).

Todo template desta pasta segue a convenção de formato definida em `.claude/CLAUDE.md`.
